Reports structural problems in the graph of a Koog strategy { } or subgraph { } block, such as a finish node that can never be reached or a node that nothing routes into.

Several of these problems otherwise surface only at run time, when the strategy initializer throws an IllegalStateException with no source location, while others are silent and simply make part of the graph never execute. This inspection catches them while you edit, reported on the offending node or edge: 


'nodeFinish' is not reachable from 'nodeStart'. The graph cannot terminate; add an edge that eventually reaches 'nodeFinish'.

Reported as errors (these crash at run time):

  • An outgoing edge from nodeFinish — the terminal node cannot have outgoing edges.
  • nodeFinish is not reachable from nodeStart, so the graph can never terminate.
  • Two nodes in the same graph share a name.

Reported as warnings (legal Kotlin, but silently wrong):

  • A node that no path from nodeStart reaches, so it never executes.
  • A reachable, non-finish node with no outgoing edge, where execution stalls.
  • A conditional edge ordered after an unconditional edge from the same node, which makes it unreachable because the unconditional edge always matches first.

Nested subgraph { } blocks are analyzed independently, each with its own start and finish node.
